# 🐦 Flappy Bird – Java Game Project

A 2D Flappy Bird game developed using Java as part of the Software Development Laboratory course (CSE-2200) at North Western University.

The game features a unique Fire Night theme, multiple difficulty levels, coin collection, increasing speed, and score tracking.

## 🎮 Project Overview

- **Project Name:** Flappy Bird
- **Programming Language:** Java
- **GUI Framework:** Java Swing
- **Graphics:** Java AWT
- **Course:** Software Development Laboratory
- **Course Code:** CSE-2200
- **University:** North Western University, Khulna, Bangladesh

## ✨ Features

- Welcome screen with difficulty selection
- Three difficulty modes: Easy, Normal, and Hard
- Unique Fire Night visual theme
- Bird movement with gravity and jumping mechanics
- Obstacle generation and collision detection
- Coin collection system
- Increasing game speed after every 5 points
- Score and high-score tracking
- Keyboard-based controls

## 🛠️ Technologies Used

- Java JDK
- Java Swing (`javax.swing`)
- Java AWT (`java.awt`)
- Java AWT Event Handling (`java.awt.event`)
- ArrayList
- Timer
- IntelliJ IDEA

## 🧠 Object-Oriented Programming Concepts

This project demonstrates the following OOP concepts:

- **Class and Object:** Used to structure the game components.
- **Inheritance:** Implemented using `JPanel` and other Java classes.
- **Encapsulation:** Game variables and methods are managed within classes.
- **Polymorphism:** Implemented through method overriding.
- **Abstraction:** Drawing methods such as `drawBird()` and `drawPipes()` simplify game graphics.

## 🎯 Game Controls

| Key | Action |
|---|---|
| SPACE | Make the bird jump |
| Mouse | Select difficulty options |

Avoid the pipes and collect coins to achieve a higher score!

## 🚀 How to Run

1. Install Java JDK on your computer.

2. Open the project in IntelliJ IDEA or another Java IDE.
3. Locate the main Java file.
4. Run the main class to start the game.
